## Hello, I'm yungmewlore 👋

I'm a developer based in Singapore who builds small, deliberate tools that make working in the terminal feel less like fighting a machine. Most of my open-source work sits at the intersection of developer ergonomics and minimalism — if a piece of software makes me reach for my mouse, I start wondering how to replace it. Lately that means Neovim plugins, lightweight Docker workflows, and CLI utilities in Go and Python.
